# Operations

## Processes

### Skill Review Process

1. **Automated Scanning**: All skills scanned on upload
2. **Risk Assessment**: Skills scored as safe, low, medium, high, or critical
3. **Auto-Publish**: Safe and low-risk skills auto-published
4. **Manual Review**: Medium-risk skills queued for review
5. **Quarantine**: High/critical risk skills blocked pending fixes

### Creator Onboarding

1. Sign up for Pro plan
2. Connect Stripe Connect account
3. Complete creator profile
4. Build first skill with PAL
5. Submit for security review

## Playbooks

### Security Incident Response

1. **Detection**: Monitor scan results for critical findings
2. **Assessment**: Determine severity and impact
3. **Containment**: Quarantine affected skills
4. **Notification**: Alert affected users
5. **Remediation**: Work with creator to fix issues
6. **Review**: Post-incident analysis

### Creator Dispute Resolution

1. Receive dispute via support
2. Review transaction details
3. Contact both parties
4. Mediate resolution
5. Escalate to Stripe if needed
