# Strategy

## Vision

Build the world's greatest skill library — a marketplace of skills for every area of work and platform.

## Mission

Democratize access to specialized tools and workflows by enabling anyone to discover, build, and sell skills.

## Core Values

1. **Security First**: Every skill is scanned for vulnerabilities
2. **Creator Economy**: Builders keep 70% of revenue
3. **Universal Access**: Skills for every platform, tool, and workflow
4. **AI-Powered**: Natural language skill generation with PAL

## Positioning

### Target Market
- Primary: Software developers and technical operators
- Secondary: Technical founders, product managers, operations teams
- Tertiary: Enterprise teams seeking custom tooling

### Competitive Advantage
- Only marketplace with built-in security scanning
- AI-powered skill generation (PAL)
- Stripe-powered marketplace with creator payouts
- AWS infrastructure for reliability and scale

### Key Differentiators
1. Security-first approach (AWS scanning)
2. PAL skill builder (AI generation)
3. Creator revenue share (70/30 split)
4. Universal skill catalog
