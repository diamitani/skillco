# Marketing

## Brand Guidelines

See `/business/branding/BRAND.md` for complete brand assets.

### Voice & Tone

- **Smart but accessible**: No jargon, no buzzwords
- **Empowering**: Focus on what users can build
- **Trustworthy**: Security-first messaging
- **Modern**: Clean, minimal, premium

### Key Messages

1. "The world's greatest skill library"
2. "Security-scanned, community-rated"
3. "Build skills with AI, sell them on the marketplace"
4. "From idea to income"

## Content Strategy

### Content Pillars

1. **Skill Tutorials**: How to use marketplace skills
2. **Security Guides**: Best practices for safe code
3. **Creator Stories**: Success stories from skill builders
4. **Industry Insights**: Trends in automation and AI
