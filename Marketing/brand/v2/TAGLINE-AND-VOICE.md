# SkillCo: Tagline, Voice and Lockup Copy

Name rule (from the research): the brand is **SkillCo**. The address **skillco.work** appears small, lowercase, monospace. Never write "SkillCo.Work" as the name.

## Recommended copy

| Element | Copy |
|---|---|
| **Primary tagline** | Skills that work. |
| **Supporting line (proof)** | Same prompt, same skill, every time. |
| **Hero headline** | Say what you need. Get the skill that does it. |
| **Hero subhead (today)** | 100+ ready-to-install skills for your AI agent, each one packaged and ready to run. |

| **Logo descriptor (under lockup)** | The skill index for AI agents |

| **Secondary CTA** | Find my skill |

Retire: "Turn Skills Into Companies". It describes the seller story, not the index-and-route product.

## Why "Skills that work." is the primary

- Four syllables, no jargon, passes the say-it-out-loud test for video voiceover.
- Means two things at once: the skills function, and you can find them at skillco.work.
- Leaves room for the proof line (#3) to do the "deterministic" job without overloading the tagline.
- Alternative if you want to lead with the differentiator: **Matched, not guessed.**

## Voice and tone

**One-line voice:** a sharp, calm engineer who explains things plainly and never oversells.

| Trait | Means | Do | Don't |
|---|---|---|---|
| Precise | Say exactly what it does | "Installs in one command." | "Supercharge your workflow." |
| Plain | Short words, short sentences | "Pick a skill. Add it to your agent." | "Leverage our solution to operationalize agentic capabilities." |
| Confident, not loud | State facts, let the product prove it | "Matched by rule, so results repeat." | "The world's most powerful AI skill engine!" |
| Honest | Only claim what ships | "100+ skills today." | "Millions of skills" (until true) |
| Builder-friendly | Assume a smart reader, not an expert | "Skill: a packaged set of instructions your agent follows." | Unexplained acronyms |

**Words we use:** skill, index, match, route, install, run, agent.
**Words we avoid:** revolutionary, supercharge, unlock, game-changing, magic, seamless, AI-powered (as a headline).
**Jargon rule:** the first time "JEV" appears on a public page, explain it in plain words ("our deterministic matching model"), or leave it off marketing pages.

## Tone by context

| Context | Tone | Example |
|---|---|---|
| Hero / marketing | Confident, short | "Say what you need. Get the skill that does it." |
| Skill page | Clear, practical | "n8n Engineer builds, debugs and documents n8n workflows. Download, drop into your agent, run." |
| Success | Calm, brief | "Skill added. Try it with: /n8n-engineer" |
| Error | Helpful, no blame | "We couldn't find a skill for that. Try describing the outcome you want, like 'clean up a lead list'." |
| Empty state | Inviting | "No skills saved yet. Browse the library and save the ones you use." |
| Loading | Sets expectation | "Matching your request to the index..." |
| Video / social | Punchy, visual | "Ask. Match. Run." |

## Microcopy set

- **Search box placeholder:** Describe what you need done
- **Search empty result:** No exact match. Here are the closest skills.
- **Download button:** Download skill (.zip)
- **Copy-install button:** Copy install steps
- **Skill card meta:** Category · (add a compatibility line only once it is verified per skill)
- **Footer line:** SkillCo · skillco.work · Skills that work.
- **404:** That skill isn't in the index. Browse all skills.
- **Email sign-off:** The SkillCo team

## Localization notes

- "Skills that work" plays on the .work domain; the pun will not carry into other languages, so translate meaning ("skills that deliver results") and keep skillco.work unchanged.
- "Matched, not guessed" is compact in English; expect 30-40% expansion in German and French on buttons and cards.
- Avoid idioms in UI strings; "Ask. Match. Run." translates cleanly as three imperative verbs.
- Keep "SkillCo" and "skillco.work" untranslated everywhere.

## Open checks

- Confirm the matching promise ("same prompt, same skill") with how the JEV model actually behaves before putting it on a public page.
- A funded edtech company named SkillCo (skillco.net) exists, so the descriptor "The skill index for AI agents" should sit close to the name in first-contact placements.
